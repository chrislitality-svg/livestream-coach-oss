# 话术评判标准（模板）

> 这是一份起步模板，按你们自己的品类和打法填写。
> 新增或改动的条目先加上【待确认】，这样的行不会进入模型；确认后删掉这个标记才生效。
> 标准应该由人来定，AI 只负责按标准执行。

---

## 一、全局规则

1. **没有就是没有。** 亮点、论证手法找不到就返回空，不要凑数。
2. **跟同品类比。** 「好」的意思是在同品类标杆里处于什么位置，而不是凭印象打分。
3. **样本不足时只测量、不评价。** 同品类标杆场次太少时，只输出「做了什么、做了多少」。

---

## 三、四级评估维度

每一项写清楚：**衡量什么**（系统里对应的数据）· **好的样子** · **差的样子**。

### 3.1 外部：形象与直播间调性

- **衡量**：画面里的服装、妆造、布景
- **好**：【待确认】按你们的品牌调性填写
- **差**：【待确认】

### 3.2 基础：口语表达

- **衡量**：语速（字/分）、填充词率、术语密度
- **好**：【待确认】
- **差**：【待确认】

### 3.3 核心：节奏与引导下单

- **衡量**：塑品 / 逼单 / 互动时长占比，行动指令密度，最长促单空窗
- **好**：【待确认】
- **差**：【待确认】

### 3.4 高阶：讲解结构

- **衡量**：讲解循环是否完整（引入 → 痛点 → 讲品 → 演示 → 价格 → 逼单 → 承接）
- **好**：【待确认】
- **差**：【待确认】

---

## 四、以后怎么改

- 每条改动先标【待确认】，审过再生效。
- 换了大模型之后，抽几场人工复核一下模型的判定有没有偏宽或偏严。
